# 🛡️ KeenKeeper

## 📌 Project Overview

**KeenKeeper** is a personal friendship management dashboard that helps users stay connected with the people who matter most. It allows you to track interactions, monitor relationship status, and set communication goals — ensuring you never lose touch in a busy world.

---

## 🚀 Technologies Used

This project is built with modern frontend tools for performance and a clean user experience:

* **React.js** – Component-based UI development
* **Tailwind CSS** – Utility-first styling
* **DaisyUI** – Pre-built UI components
* **React Hooks** – State and lifecycle management
* **React Router DOM** – Navigation and routing
* **React Icons / Lucide React** – Icons and visuals

---

## ✨ Key Features

### 1. 📊 Interactive Dashboard

* Overview of total friends and relationship status
* Highlights who is **On Track**, **Almost Due**, or **Needs Attention**
* Clean and responsive card-based layout

---

### 2. 🕒 Activity Timeline & Filtering

* Track all interactions (Calls, Texts, Videos)
* View activities in a chronological timeline
* Search and filter interactions easily

---

### 3. 📈 Analytics & Goal Setting

* Visual insights into communication patterns
* Track interaction types with charts
* Set personalized goals (e.g., “Connect every 10 days”)
